# 🤖 TaskMind AI

### Plan. Focus. Achieve.

TaskMind AI is a smart, modern daily task and reminder app designed to help you organize your day, stay focused, and complete your goals.

## ✨ Features

- 🤖 AI-powered task suggestions
- 📝 Add, edit, and delete tasks
- ⏰ Custom reminders
- 🔔 Reminder notifications
- 🎵 Custom reminder ringtone
- ⭐ Task priorities
- 🔥 Productivity streaks
- 📊 Statistics and progress tracking
- 🍅 Focus/Pomodoro timer
- 💡 Smart "What next?" suggestions
- ✨ Daily planning
- ⚡ Quick task mode
- 🔎 Task search
- 🔄 Recurring tasks
- 💾 Local data storage
- 📤 Export and import backups
- 📱 Mobile-friendly interface
- 🖥️ Desktop-friendly interface
- 📲 Installable as a Progressive Web App (PWA)
